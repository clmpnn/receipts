## 📖 About

**receipts** is a lightweight web app for generating clean, professional-looking receipts in seconds — enter your details, add line items, and get a ready-to-share receipt instantly.


## ✨ Features

- 🧾 Custom line items with quantity, unit price, and computed totals
- 🧮 Automatic subtotal, tax, and grand total calculation
- 🎨 Clean, print-ready receipt layout
- 📤 Export or download as an image / PDF
- ⚡ Fully client-side — no account, no backend, no data leaves your browser
- 📱 Responsive design, works on mobile and desktop

## 🛠️ Getting Started

```bash
git clone [https://github.com/clmpnn/receipts.git](https://github.com/clmpnn/receipts.git)
cd receipts
npm install
npm run dev
```

Then open `http://localhost:3000` (or the port shown in your terminal).
